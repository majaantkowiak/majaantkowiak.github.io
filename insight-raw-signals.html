Why Raw Signals May Matter More Than Fault Codes

A diagnostic trouble code can tell us that a defined condition has been detected. A raw electrical signal, however, may contain much more information about how the component actually behaves before that final diagnostic decision is made.

01 / Diagnostic decision

A fault code is often the end of the process

A diagnostic trouble code is usually generated after a diagnostic condition has been satisfied. From the driver's or service technician's perspective, the code is extremely useful because it provides a clear indication that the control system has recognised an abnormal state.

But this information is already highly processed. The original sensor or actuator signal has passed through control logic, thresholds and diagnostic rules before being converted into a discrete diagnostic message.

02 / Signal information

The raw signal preserves system dynamics

A raw waveform contains information about how a component responds over time. Rise rate, transient behaviour, oscillations, phase duration and repeatability can all describe physical processes that are no longer visible in a simple pass-or-fail result.

This does not mean that every small signal variation represents a fault. Instead, it means that the signal provides a richer source of information from which meaningful diagnostic features can be extracted.

01

Fault code

A compact diagnostic decision generated after specific conditions are satisfied.

02

Raw signal

A time-dependent record containing details about the dynamic behaviour of the component.

03 / Feature extraction

The useful information is often hidden in signal features

Analysing a signal does not necessarily mean storing and comparing thousands of individual samples. Instead, characteristic features can be extracted to describe relevant parts of the waveform.

Amplitude

Peak values, mean levels or characteristic operating amplitudes.

Timing

Rise time, event duration, transition points and time delays.

Signal shape

Slopes, transient characteristics and phase-specific behaviour.

Frequency content

Periodic ripple, oscillations and spectral components that may not be obvious in time plots.

The objective is not to replace fault codes. Signal analysis provides an additional layer of information that can support more detailed condition assessment.

04 / Control system

Control can reduce the visible symptoms

Modern vehicle controllers continuously use feedback and correction strategies to maintain the required operating conditions. This is one of the major strengths of electronic control systems.

It also means that a component may begin to behave differently while the overall system still compensates for part of that deviation. The final vehicle-level symptom may therefore appear later than the change visible directly in a component signal.

→

This is one reason why monitoring the component signal itself can be interesting for degradation-oriented diagnostics.

05 / Thresholds

Before the threshold there may be a trend

Conventional diagnostic logic frequently needs a sufficiently clear deviation before it can classify the situation as abnormal. Before this point is reached, the measured signal may already be changing gradually.

Looking at repeated measurements, reference comparisons and trends can therefore provide a different perspective from looking only at the moment when a threshold is crossed.

01
Reference condition

Establish the characteristic behaviour of the healthy or baseline system.

02
Feature tracking

Observe changes in selected parameters over repeated operating events.

03
Condition interpretation

Evaluate whether the observed deviations may indicate a meaningful change in component behaviour.

06 / Diagnostic strategy

Signals and fault codes should complement each other

Fault codes remain essential for practical vehicle diagnostics. They provide standardised information that can quickly guide troubleshooting.

Raw-signal analysis serves a different purpose. It can support deeper investigation of dynamic behaviour, reference comparison and condition monitoring. The strongest diagnostic strategy is therefore not necessarily signal analysis instead of fault codes, but a combination of both levels of information.

Fault-code level

Clear diagnostic decision, practical servicing information and system-level fault indication.

Signal level

Dynamic component behaviour, subtle deviations, feature trends and physical interpretation.

07 / My perspective

Why I work with injector current signals

In my research, the injector current waveform is treated as a source of information about the physical behaviour of the electromagnetic injector. Instead of reducing the measurement to one value, I analyse characteristic phases, time-domain parameters and frequency-domain features.

Mathematical modelling, multidomain simulation and laboratory measurements are used together to investigate which signal changes may be connected with changes in injector condition.

Research objective: move from simple signal observation toward physically interpretable indicators of injector technical condition.
